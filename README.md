<summary><b>📡 Decode the research signal</b></summary>
<br>

- 🌧️ **GatedResidual** — an 11,107-parameter safety gate for all-in-one UHD restoration; **+10.13 dB average recovery** over ungated wrong-route outputs in deliberate misclassification stress tests.
- 🧭 **RGB-D Pose** — D435i + DINOv2/SIFT + confidence-aware RANSAC/Kabsch. Known-pose synthetic check: **0.084° / 1.6 mm**; independent real-pose ground truth is still on the quest board.
- 🦾 **ConfMate** — multi-view Chamfer/CLIP matching, abstention, partial-observation tests, and a four-object Panda peg-hole mission. Oracle control and actual visual matching stay explicitly separate.
- ✨ **DepthForce** — depth motion into a 150k-particle CUDA field; synthetic mode reaches **119–122 FPS** on an RTX 3060 Laptop GPU.

</details>
